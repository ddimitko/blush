# Lunara iOS App

## Production Branch (ios-main)

This is the production branch for the Lunara iOS app. It contains the stable, production-ready code for the native iOS application.

### Architecture
- **Platform**: iOS 17+ with Swift 6.1.2
- **Security**: Keychain Services for secure token storage
- **Payments**: Stripe integration with in-app payment flows
- **Real-time**: WebSocket support for notifications and slot updates
- **Features**: Full feature parity with web app including shop management and dashboard

### App Store
This branch is used for App Store releases and production deployments.

### Branch Structure
- `main` - Production webapp code
- `ios-main` - Production iOS app code  
- `develop` - Development webapp code
- `ios-develop` - Development iOS app code

For development work, please use the `ios-develop` branch.
