# Lunara - Beauty Booking Platform

## Production Branch (main)

This is the production branch for the Lunara webapp. It contains the stable, production-ready code for the beauty booking platform.

### Architecture
- **Backend**: Spring Boot 3+ with PostgreSQL, Redis, WebSockets, RabbitMQ
- **Frontend**: React with TypeScript and shadcn/ui
- **Payments**: Stripe Connect with comprehensive compliance
- **Real-time**: WebSocket-based slot locking and notifications
- **Security**: JWT authentication, CSRF protection, rate limiting

### Deployment
This branch is automatically deployed to production environments.

### Branch Structure
- `main` - Production webapp code
- `ios-main` - Production iOS app code  
- `develop` - Development webapp code
- `ios-develop` - Development iOS app code

For development work, please use the `develop` branch.
